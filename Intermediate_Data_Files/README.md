coldshocksurvival_scaledaverages.csv = file generated in coldshocksurvival_finalscript.R that contains the average cold shock survival for each combination of diapause, acclimation, and cold shock treatment. This data has been scaled to the average survival of the control groups.

met_pairwise_contrasts_stats.csv = file generated in Metabolite_IndMetTests.R script. For each metabolite, the overall p tells you whether any of the six total treatment groups differed in that metabolite. Then there are p values and log2FC values for each of the five planned pairwise contrasts.

lip_headgroup_pairwise_contrasts_stats.csv = file generated in Lipid_IndMetTests.R script. For each phospholipid headgroup class, the overall p tells you whether any of the six total treatment groups differed in that class. Then there are p values and log2FC values for each of the five planned pairwise contrasts.

lip_fa_pairwise_contrasts_stats.csv = file generated in Lipid_IndMetTests.R script. For each fatty acyl methyl ester species, the overall p tells you whether any of the six total treatment groups differed in that species. Then there are p values and log2FC values for each of the five planned pairwise contrasts.
