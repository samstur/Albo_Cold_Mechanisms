
## Cold Shock Survival Data Files
coldshocksurvival_finaldata.csv = the datafile containing the cold shock survival for each replicate in the experiment

## Metabolite and Lipid Data files
Metabolite_RawData.csv = raw data on the relative levels (peak area) of 50 metabolites of interest in each egg sample. This data has not yet been scaled to the mass of each sample.

PhospholipidClass_RawData.csv = raw data on the relative levels of the phospholipid headgroup classes in each egg sample. Note that in this file diapause treatment abbreviations are: LD = non-diapause; SD = diapause. Acclimation treatment abbreviations are: PREACC = Before acclimation; WARM = warm acclimation 15-d; COLD = cold acclimation 15-d.

FattyAcyls_molarprops_RawData.csv = raw data on the molar proportions of each fatty acyl methyl ester species in each egg sample. Note that in this file diapause treatment abbreviations are: LD = non-diapause; SD = diapause. Acclimation treatment abbreviations are: PREACC = Before acclimation; WARM = warm acclimation 15-d; COLD = cold acclimation 15-d.

met_abbreviations.csv = this table provides a list of abbreviations for the metabolites. Used in analysis and visualization scripts

SampleInfo_Fall2024.csv = this table provides additional information on each of the samples collected for metabolite and lipid analyses, including what parental cage they were derived from. Used in analysis and visualization scripts
